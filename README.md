# AnimeSpace
AnimeSpace — современная платформа для просмотра и поиска аниме. Удобный каталог, популярные тайтлы, жанры, избранное и история просмотра.

## Откуда берётся видео
Плеер на странице аниме работает так:

1. **AniLibria (AniLiberty)** — основной источник. Открытый API `anilibria.top/api/v1`, **токен не нужен**. Отдаёт HLS-потоки 480/720/1080p, серии и тайминги опенинга/эндинга (кнопка «Пропустить»). Серия и время просмотра запоминаются в браузере.
2. **Kodik** — необязательный запасной источник. Включается, только если в Vercel задан `KODIK_TOKEN`
   (Settings → Environment Variables; можно `KODIK_TOKEN_2`, `KODIK_TOKEN_3` или список через запятую в `KODIK_TOKENS`), затем Redeploy.

Эндпоинты бэкенда (`api/anime.js`): `type=watch` (AniLibria), `type=kodik`, `type=details`, `type=top`, `type=search`, `type=schedule`.

Если у релиза включена блокировка правообладателя или по региону, плеер покажет сообщение и ссылку на AniLibria.
